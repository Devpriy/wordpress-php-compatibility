# WordPress White Screen / Blank Page — Troubleshooting & Fix

A practical guide for diagnosing and resolving WordPress websites that display a completely blank page, white screen, or partially broken frontend/admin.

A WordPress white screen can happen after a plugin update, theme change, PHP upgrade, custom code change, memory issue, or a server-side PHP error.

The correct approach is to identify the root cause before making changes.

---
